# 《DeepSeek Harness 实战手册》零成本发布与传播攻略

> 目标：**一分钱不花**，让这本书"人人都能看"，并且尽可能多地被人看到。
> 写作时间：2026-08-16（DeepSeek Harness 发布第 3 天，热度窗口期）

## 一、先认清三件事

1. **微信读书商城正式上架 = 必须 ISBN 出版 = 至少几万元**，零成本做不到，直接放弃这条路。
2. **微信读书生态里有一扇免费的门：公众号。** 读者在微信读书里搜索你的公众号名字，就能把它当"一本书"加入书架，阅读你的文章。这就是零成本实现"发到微信读书、人人都能看"的正规路径。
3. **网页版人人可读**：GitHub Pages / 知乎 / 掘金发布后，任何人点链接就能读，不需要装任何 App。

本攻略按"最推荐 → 备选"排序，全部免费。

## 二、路线 A（最推荐）：公众号 + 微信读书

### 第 1 步：注册微信公众号（个人订阅号，免费）

1. 打开 `mp.weixin.qq.com`，用你的微信扫码注册；
2. 类型选 **订阅号 → 个人**（个人即可注册，免费）；
3. 按提示做实名认证（需要身份证 + 绑卡微信，这是唯一的"身份成本"，不花钱）；
4. 给公众号起名。**名字要可搜索、好记**，例如：
   - `DeepSeek Harness 实战`
   - `dsh 中文手册`
   - `AI Harness 研究所`
5. 完成注册后，公众号即出现在微信读书的搜索范围里（同步有延迟，一般 1-3 天，可以先发文章再验证）。

### 第 2 步：把书拆成 5 篇文章（系列化）

不要一口气把 6 万字扔上去，公众号适合系列连载。按下面的拆分，每篇 3000-6000 字：

| 篇 | 标题（可微调） | 内容来源 | 钩子 |
|---|---|---|---|
| 1 | DeepSeek Harness 是什么？为什么发布 48 小时就 10 万 Star | 前言 + 第 1 章 | 热度新闻 + "这篇文章可能是全网第一篇系统中文教程" |
| 2 | 五分钟上手：一行命令跑起 DeepSeek Harness Web UI | 第 3 章 | 保姆级图文步骤，照做必成 |
| 3 | 无头模式与 Python SDK：把 AI Agent 变成你的自动化流水线 | 第 4、5 章 | 代码即生产力，脚本化演示 |
| 4 | 手把手写第一个插件：Hello World 到 greet 工具 | 第 6、7 章 | "以后给 agent 加能力，不用等官方" |
| 5 | 一切皆插件的架构，究竟是怎么设计的？ | 第 2、9 章 + 附录 | 深度文，建立"权威"感 |

每篇末尾放一句话引导："全本手册（含插件打包发布、实战案例、FAQ）已整理成书，微信读书搜索【公众号名】即可加入书架，或回复 '手册' 获取网页版链接。"

### 第 3 步：读者在微信读书里怎么看

把下面这段**操作说明**写进你的公众号欢迎语和朋友圈文案：

> 打开微信读书 App → 顶部搜索【你的公众号名】→ 分类选"公众号"→ 找到账号后点击进入，加入书架即可。以后更新会自动同步。

也可以在微信读书的"我 → 设置 → 隐私"里开启"微信公众号文章"授权同步，收藏的文章会自动进书架。

### 第 4 步：合规与体验细节

- 文章开头标注："本文基于 DeepSeek Harness 官方仓库，写作于 2026 年 8 月，开发者预览版如有变更以官方为准"——既免责，又显得严谨；
- 每篇声明原创（群发前勾选"原创声明"），方便别人转载时带上你的名字；
- 代码块在公众号编辑器里用"代码片段"功能插入，避免被折叠。

## 三、路线 B（立刻可见）：GitHub Pages 网页版

如果你不想等公众号审核，**今天就先把网页版挂出去**：

1. 注册 GitHub（免费）；
2. 新建仓库，名字随意，比如 `dsh-book`；
3. 把 `DeepSeek-Harness实战手册.html` 上传到仓库根目录，重命名为 `index.html`（可选）；
4. 仓库 → Settings → Pages → 选分支 main，根目录，保存；
5. 几分钟后，你的书就有一个公开网址：`https://你的用户名.github.io/dsh-book/`。

把这个链接发到任何地方，人人可读、无需登录、无广告。也可以把链接做成二维码印在公众号文章里。

> 本项目的实际部署地址（已上线）：**https://zoahdev.github.io/deepseek-harness-handbook/**

## 五、"一定要火"的现实打法

先说实话：**没有任何人能保证爆火**。但热度窗口期的内容，概率可以人为拉高。下面每一步都做，把运气变成概率：

### 1. 抢时间

发布才第 3 天，中文系统教程几乎没有。**今天发第一篇，你就是"全网首发系列"**；下周发，就是"又一篇教程"。这个差异比内容本身还大。

### 2. 标题公式（三选一）

- 悬念型：《发布 48 小时 10 万 Star，DeepSeek Harness 到底凭什么》
- 利益型：《一行命令跑起 DeepSeek Harness：安装、配置、写插件全教程（免费）》
- 稀缺型：《可能是全网第一本 DeepSeek Harness 中文手册》

### 3. 开场 100 字钩子（模板）

> 8 月 13 日晚，DeepSeek 开源了 Harness。2 小时破万 Star，48 小时破 10 万。但大部分中文读者看到的只有新闻标题，没人告诉他们怎么用。这篇文章/这本书，就是来补这个缺口的——从安装到写插件，全中文，全免费。

### 4. 48 小时传播清单

- 发朋友圈 + 3 个技术微信群（附网页链接，别只发文件）；
- 知乎提问下回答 + 1 篇文章；
- 掘金、CSDN 各发 1 篇（复用公众号内容，改标题防重复）；
- 微博/即刻带话题 `#DeepSeek Harness#`；
- 拉你认识的 3-5 个开发者朋友"求转发"，冷启动阶段人脉比算法有用；
- 48 小时后看数据（阅读、收藏、转发），哪个平台给量，就把后续几篇重点发哪。

### 5. 让读者帮你传播

- 文末加一句"转载随意，注明出处即可"——转载就是免费的渠道；
- 把网页版做成"全文免费"，PDF/EPUB 作为"微信读书可导入版"提供；
- 保留更新：官方每次大版本更新，你更新一版"新特性解读"，持续吃流量。
