## 视频 2（教程篇 · 5 分钟上手）

**【封面字】** 一行命令跑起 DeepSeek Harness

**【口播】**（约 75 秒）

> 上条视频讲了 DeepSeek Harness 是什么，这条教你五分钟跑起来。
>
> 第一步：装 Node.js，版本 22.19 以上。命令行输入 node -v 检查。
> 第二步：一行命令启动：
>
> npx @deepseek-ai/dsh web
>
> 第三步：浏览器打开 http://127.0.0.1:3080。
> 第四步：设置 → 模型，填你的 DeepSeek API Key。
> 第五步：选一个工作区，比如你手头的项目目录，然后发任务。
>
> 比如你让它："跑一遍测试，把失败的那几个修好"。
> 它会自己读代码、改文件、跑命令，需要动你东西的时候先问你审批。
>
> 注意：Key 只写、存本地、不会上传。
>
> 想要插件开发教程的，关注我，看下一个视频。

**【画面】** 全程录屏：终端输入命令 → 浏览器 UI → 配置页 → 发任务过程。每步配字幕。

## 视频 3（避坑篇 · 收藏向）

**【封面字】** 程序员必存！DeepSeek Harness 三个大坑

**【口播】**（约 70 秒）

> 玩 DeepSeek Harness 之前，这三个坑一定看完，尤其第三个。
>
> 坑一：它是开发者预览版，以后会有破坏性更新。生产环境别追最新，锁版本，升级前看官方 Release。
>
> 坑二：从 GitHub 装插件，pnpm 默认不跑构建脚本，第一次装会失败。
> 解决：作者写 prepare 脚本，你在 profile 的 pnpm-workspace.yaml 里显式授权。
> 但注意——授权等于允许它的代码在你电脑上执行，**只信你信得过的源码**。
>
> 坑三：有些组合默认是全权限的，danger-full-access，能改你任何文件。
> 永远在容器或者可丢弃的目录里跑。
>
> 还有一条铁律：API Key 千万别提交进 git。
>
> 完整的 17 章手册，评论区置顶自取。

**【画面】** 三屏排版：每讲一个坑配一个红色警示卡；结尾放"安全三红线"总结图。
